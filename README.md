# Moyo & Ranye Wedding Website

React/Vite implementation based on the supplied Figma screenshot.

## Run locally

```bash
npm install
npm run dev
```

## Before publishing

1. Replace the SVG placeholders in `public/images/` with the real couple, venue, accommodation and dress-code photos.
2. Replace the placeholder bank account details in `src/main.jsx`.
3. Confirm the venue if the Lagos/Ibadan decision changes.
4. Connect the RSVP handler to Google Sheets, Formspree, Supabase, or another backend.
5. Change the countdown time in `src/main.jsx` if the ceremony starts at a different time.
